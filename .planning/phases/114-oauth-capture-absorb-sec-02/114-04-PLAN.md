<objective>
Build the new `capture.rs` module: an in-memory, session-scoped, zeroized phantom-token store
(mint/resolve/admit) plus the portable response-rewrite logic — JSON dot-path field rewrite,
JWT-shaped phantom construction, and the fail-closed "reject if an unconfigured token-shaped field
survives rewrite" backstop. This is the D-07 "port the logic, rebuild the plumbing" module: the
algorithms are adapted directly from upstream's `oauth_capture/{jwt,rewrite}.rs` (CITED, full
files read during research), but the storage shape is new (a `HashMap<phantom, real>` reverse
store, not upstream's `forward.rs`-coupled abstraction).

Purpose: give Plan 114-05/114-06 (the `reverse.rs` enforcement point) a tested, self-contained API
to call — mint a phantom for a captured real token, rewrite a response body's configured fields,
and fail closed if an unconfigured token-shaped field is found unrewritten.
Output: `crates/nono-proxy/src/capture.rs` with `CapturePhantomStore`, its `mint`/`resolve`/`admit`
methods, `rewrite_response_fields()`, `reject_unrewritten_token_fields()`, `jwt_shaped_phantom()`,
and a `#[cfg(test)] mod tests` covering all of the above.

```rust
pub(super) fn jwt_shaped_phantom(phantom: &str) -> Result<String> {
    let header =
        base64::engine::general_purpose::URL_SAFE_NO_PAD.encode(br#"{"alg":"none","typ":"JWT"}"#);
    let payload = serde_json::json!({
        "iss": "nono", "sub": phantom, "aud": "nono",
        "iat": 0, "exp": 4_102_444_800_u64
    });
    let payload = base64::engine::general_purpose::URL_SAFE_NO_PAD
        .encode(serde_json::to_vec(&payload).map_err(...)?);
    Ok(format!("{header}.{payload}.{phantom}"))
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Upstream OAuth response body -> capture store | Untrusted response content is JSON-parsed and scanned; malformed/oversized input must fail closed, never panic |
| Capture store -> memory | Real tokens live in-process memory only; process compromise, core dump, or swap are the residual exposure surface (D-08 accepted cost) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-114-06 | Information Disclosure | `StoredCapture.real` | mitigate | `Zeroizing<Vec<u8>>`, zeroized on drop; never written to disk (D-08) |
| T-114-07 | Elevation of Privilege | `CapturePhantomStore::resolve()` | mitigate | Per-phantom `admitted_consumers` scoping; `resolve()` returns `None` uniformly for both "not found" and "not admitted" to avoid an existence oracle |
| T-114-08 | Information Disclosure | `reject_unrewritten_token_fields` | mitigate | Fail-closed backstop against provider-config drift — a token-shaped field the operator forgot to declare in `response_fields` still gets caught, not silently forwarded |
| T-114-09 | Denial of Service | `value_at_path_mut` on malformed/deeply-nested JSON | mitigate | Traversal only descends into `.as_object_mut()`, returns `None` (not panic) on any non-object intermediate; bounded by the response body's own D-05 size cap (enforced by the caller, Plan 114-05) |
</threat_model>
