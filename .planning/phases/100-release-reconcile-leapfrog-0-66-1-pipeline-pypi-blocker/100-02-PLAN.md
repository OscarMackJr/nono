| T-100-04 | Elevation of Privilege (secret-scoped network call) | `cargo search` idempotency check inside a job holding `CARGO_REGISTRY_TOKEN` | accept | `cargo search` is a read-only public registry query, unrelated to the token scope; verified functional live per RESEARCH Pitfall 6; MEDIUM-durability, documented fallback (`cargo info`) if crates.io deprecates search |
