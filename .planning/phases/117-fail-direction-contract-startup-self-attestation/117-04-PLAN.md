<objective>
Migrate the shipped `WINDOWS_WFP_TEST_FORCE_READY` / `NONO_TEST_HARNESS` runtime-gated fault
injection toggle to a compiled-out `#[cfg(feature = "layer-fault-injection")]` shape, resolving
SC4-4, and add the `layer-fault-injection` feature to `crates/nono-cli/Cargo.toml` so later plans
(06, 07) can gate their own per-layer hooks behind the same flag.

Purpose: D-30 is explicit that a runtime-gated "turn off a confinement layer" switch is live attack
surface in a security tool — an env var an attacker with process-spawn control can set in every
release binary today. This plan removes that surface for the WFP row and establishes the pattern
the other layers' hooks copy.
Output: new Cargo feature; WFP toggle recompiled out of default builds.
</objective>
