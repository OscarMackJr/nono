<objective>
Close WR-26 — the banner and the operator warn name the Windows Application event log
unconditionally, but three common conditions leave nothing there.

WR-15 replaced a nonexistent "audit ledger" pointer with *"layer detail is in the Windows
Application event log (source `nono`, event id 10011)"*. That destination receives the record only
when **all three** hold, each confirmed by direct read in this planning session:

1. `crate::telemetry::SECURITY_LAYER.get()` is `Some(..)` — the `None` arm at `launch.rs:1519-1526`
   warns and emits nothing at all;
2. `inner.config.enabled` is `true` — `emit_attestation_event`'s emit closure is gated `if enabled`
   at `attestation_downgrade_event.rs:136`, and `enabled` is driven by the HKLM `MachineEgressPolicy`
   telemetry control an administrator can switch off. Critically, the function still returns
   `Ok(chain_head)` in that case (`:150-152`), so **the caller currently cannot tell an emission
   from a chain advance**;
3. `RegisterEventSourceW` succeeds — otherwise the record goes to stderr instead (CR-05, being
   repaired one wave earlier by 117-37).

In each case the operator is sent to a destination that provably has no record. This is the same
defect class WR-15 was written to close, reintroduced by making the pointer *unconditional*
instead of conditional on the emission having actually happened — and it is the same class as
WR-27 (`main.rs`'s non-label arm), which 117-39 fixes at its own single site one wave earlier.

Two sites remain unconditional: `output.rs:115-125` (the banner) and `launch.rs:1556-1562` (the
operator warn). **Fixing exactly those two would repeat this phase's defining failure** — three
consecutive rounds each produced the next round's blocker by fixing the enumerated sites and not
the class. So the deliverable here is not two edits; it is a gate over every operator-facing
destination pointer in the workspace, with these two brought into compliance as its first
consumers.

Purpose: make "we told the operator where to look" a property the build checks, rather than a
sentence three separate plans have now each written by hand.
Output: a `DowngradeDetailChannel` computed from the real emission outcome, threaded into both
sites; a `None` rendering that states the truth and gives a working action; and a class gate
covering all destination-naming strings including `main.rs`'s.
</objective>
