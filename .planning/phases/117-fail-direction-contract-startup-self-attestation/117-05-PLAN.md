<objective>
Add a policy-free, platform-neutral attestation primitive to `crates/nono`: a shared 4-state status
type (D-18) plus the raw OS probe functions (D-17) that query a suspended child process's actual
token/job state from outside it. This is the library-side half of CINT-02 — mechanical
observation, no policy about which layers are required or what a missing layer should do (that
stays CLI-side per D-02, built in Plan 08).

Purpose: three independent spawn sites (`exec_strategy_windows/launch.rs`,
`nono-shell-broker/src/main.rs`, `agent_daemon/launch.rs`) all need to observe a suspended child's
real OS state before `ResumeThread`. Only two of those three are in the `nono-cli` crate; the
broker is a separate binary that already links `nono` directly. Putting the mechanical probes here
gives all three call sites one shared, tested primitive instead of three independent
re-implementations of `GetTokenInformation`/`IsProcessInJob` calls (RESEARCH finding 1).
Output: `crates/nono/src/attestation.rs` (new), wired into `crates/nono/src/lib.rs`.
</objective>

**Warning-6 fix (checker pass 2, 2026-08-09): `windows_sys::Win32::Foundation::HANDLE` is not a
portable type.** `crates/nono/Cargo.toml` only declares `windows-sys` under
`[target.'cfg(target_os = "windows")'.dependencies]` — off-Windows, the crate is not even a
dependency, so a non-cfg-gated function signature naming `HANDLE` directly fails to compile on
Linux/macOS, and the D-11 stub functions (`#[cfg(not(target_os = "windows"))]`) cannot reference
`HANDLE` either. Fix: define a platform-neutral alias in this file —
`#[cfg(target_os = "windows")] pub type ProcessHandle = windows_sys::Win32::Foundation::HANDLE;`
`#[cfg(not(target_os = "windows"))] pub type ProcessHandle = ();` — and use `ProcessHandle` (never
raw `HANDLE`) in every one of the four `pub fn probe_*` signatures, both the real
`#[cfg(target_os = "windows")]` implementations and their `#[cfg(not(target_os = "windows"))]`
stubs. On Windows this is a zero-cost type alias (`ProcessHandle` IS `HANDLE`); off-Windows it is
the unit type, matching D-11's "platform-neutral types compile everywhere" requirement without
touching the real Windows behavior at all.

| T-117-02 | Spoofing | attestation trusting a self-report | mitigate | D-19 invariant enforced structurally: every function in this module takes a `ProcessHandle` and performs an OS query against it — there is no function signature anywhere in this module that accepts a claim string/struct FROM the target process.
