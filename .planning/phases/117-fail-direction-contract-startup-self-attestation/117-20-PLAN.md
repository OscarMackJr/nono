<objective>
Close CR-01 (BLOCKER, security-relevant): `AppliedLabelsGuard::snapshot_and_apply`'s residue-equivalence
predicate compares only `(rid, mask)`, so a structurally-inert `INHERIT_ONLY_ACE` mandatory-label ACE
is indistinguishable from the effective ACE nono itself writes. A launch whose only on-disk ACE is
inherit-only can report `MandatoryIntegrityLabel` fully `Confirmed` with zero effective enforcement —
verbatim the CR-14 defect this phase exists to close, reopened by Plan 117-13's NR3-01 fix.

This plan widens the ACE reader to also return `AceFlags`, requires the residue predicate to reject
`INHERIT_ONLY_ACE` (while still accepting `INHERITED_ACE`, which the OS DOES evaluate), reorders the
predicate to run only after the ownership gate (WR-01 — residue can only be adopted on a path nono
itself could have labelled), corrects two doc comments that assert a "last session out restores"
property the code does not implement (WR-02 disposition: document the true property rather than
build a cross-session refcount mechanism), and restores/extends test coverage a prior plan silently
broke (WR-03).

Purpose: an attested `MandatoryIntegrityLabel` layer must mean the object actually carries an
effective, OS-evaluated mandatory-label ACE — never a residue-shaped ACE the OS ignores.
Output: `crates/nono/src/sandbox/windows.rs` and `crates/nono-cli/src/exec_strategy_windows/labels_guard.rs`
with the widened reader, the corrected predicate, and non-vacuous positive/negative tests.
</objective>

```
pub fn low_integrity_label_and_mask(path: &Path) -> Option<(u32, u32)>
```

Returns `Some((rid, mask))` for the first `SYSTEM_MANDATORY_LABEL_ACE` found by `AceType`, walking
`GetNamedSecurityInfoW(..., LABEL_SECURITY_INFORMATION, ...)`'s SACL via `GetAce`. It reads
`header.AceType` but never `header.AceFlags`. `ACE_HEADER` (from `windows_sys::Win32::Security`) has
fields `AceType: u8`, `AceFlags: u8`, `AceSize: u16`.

`windows_sys::Win32::Security` exports `INHERIT_ONLY_ACE: ACE_FLAGS = 8u32` and
`INHERITED_ACE: ACE_FLAGS = 16u32` (both `ACE_FLAGS = u32`; `header.AceFlags` is `u8` — cast with
`u32::from(header.AceFlags)` before bitwise comparison against these constants).

`try_set_mandatory_label` (line ~1045) writes SDDL `"S:(ML;;0x{mask:X};;;LW)"` — an EMPTY ACE-flags
field, i.e. the ACE nono itself writes always has `AceFlags == 0`.

Existing callers of `low_integrity_label_and_mask` (must keep compiling unchanged): 4 call sites in
`crates/nono/src/sandbox/windows.rs`'s own test module (2-tuple destructuring `let (rid, mask) = ...`),
`crates/nono-cli/src/exec_strategy_windows/labels_guard.rs` (many call sites, mostly in its test
module), and `crates/nono-cli/src/hook_runtime_windows.rs:590`
(`if let Some((rid, _mask)) = nono::low_integrity_label_and_mask(&canonical)`).
