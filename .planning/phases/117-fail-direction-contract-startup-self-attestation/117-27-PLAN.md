<objective>
Close the iteration-5 BLOCKER and two related warnings in `apply_startup_attestation_gate`'s
`ProceedDowngraded` arm (`crates/nono-cli/src/exec_strategy_windows/launch.rs:1480-1567`):

- **CR-03 (BLOCKER):** Plan 117-21's D-28 gate was applied to only 1 of the 3 sites in this same
  function that put specific `LayerId` names on the shared console. Two audit-emission warns
  (`SECURITY_LAYER.get() == None` at `:1496-1503`, and `emit_attestation_event`'s `Err` arm at
  `:1505-1513`) still interpolate `downgraded_layers={dedup_key}` into message TEXT, ungated, on the
  default no-`--log-file` arm where `init_tracing_with_security` writes to `std::io::stderr` — a
  channel the confined child shares. The existing withholding test asserts only on *field* names
  and is structurally blind to a leak in message text, by construction.
- **WR-15:** The banner (`output.rs::print_attestation_downgrade_banner`) and the withheld-detail
  warn both point the operator at "the audit ledger" — `LayerAttestationDowngraded` never reaches
  `audit-events.ndjson`; it goes to the Windows Application Event Log (event id 10011) via
  `emit_attestation_event`, or nowhere at all if telemetry is disabled and `--log-file` was not set.
- **WR-16:** `log_target_is_private()` treats "a `--log-file` was opened" as proof the confined
  child cannot read it, without checking whether the resolved log path falls inside a directory this
  launch's own `CapabilitySet` grants the child read/write access to (the overwhelmingly common
  invocation `nono run --workspace . --log-file .\nono.log ...` puts the log file exactly there).

Purpose: three fixes to the same channel-honesty defect class — gate every emission site the same
way (not one of three), point operators at a channel that actually holds the data, and make the
private-channel predicate mean what its name claims.
Output: a single `layer_detail` computation reused by all three emission sites; a
granted-path-aware `log_target_is_private()`; corrected banner/warn destination text.
</objective>
