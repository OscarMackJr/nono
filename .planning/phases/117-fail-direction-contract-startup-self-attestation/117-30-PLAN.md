<objective>
Close WR-20: Plan 117-20's WR-01 reorder (ownership gate now runs before the residue-equivalence
check) is correct on the merits — nono structurally cannot label a path it does not own, so the
skip is D-02-exempt either way — but it silently loosened the layer's coverage arithmetic as a side
effect of a fix framed around provenance. Before the reorder, a path that was BOTH non-owned AND
carrying a foreign mandatory label recorded `SkipPreExistingLabel` (counted as a genuine coverage
gap, downgrading the claim). After the reorder, `Ok(false)` records `SkipNotOwned` and `continue`s
before `low_integrity_label_ace` is ever called — the same path is now silently contract-exempt and
uncounted. `guard_skips_path_not_owned_by_current_user` (the existing regression test for the
ownership gate) uses `C:\Windows`, whose label state on a given host is incidental — it pins neither
the old nor the new behavior for the combined condition. No test in the tree currently controls
both variables (non-owned AND foreign-labeled) at once.

Purpose: pin the reclassification with a test that actually constructs both conditions
simultaneously, so a future edit cannot silently move this state back to a coverage gap (or further
away from one) without a test noticing.
Output: a new regression test constructing a real non-owned, foreign-labeled path via ownership
reassignment.
</objective>
