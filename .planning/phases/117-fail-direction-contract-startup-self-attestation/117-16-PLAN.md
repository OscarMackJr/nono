<objective>
Close NR3-04 (the D-27 banner points the operator at a diagnostic channel that carries nothing on
the success path) and add the one genuinely-missing per-row test for `FirewallRulesEgress` — both
land in `launch.rs`, in different, non-overlapping regions of the file.

**NR3-04:** the human-visible downgrade banner reads "see diagnostic output for details", but
`apply_startup_attestation_gate`'s `ProceedDowngraded` arm only logs `downgraded_layers=` inside the
`None`/`Err` arms of audit-event emission — i.e. only on FAILURE to emit the audit record. On the
common, successful path the banner points at a channel that is never written. The daemon's own
mirror (`agent_daemon/launch.rs:965-972`) already does this correctly — logs `downgraded_layers`
unconditionally via `tracing::warn!`, which routes to the log file / Event Log, never to the
confined child's stderr (D-28 is not implicated: `tracing` here is not the channel the child
shares).

**SC3/FirewallRulesEgress:** unlike the WFP row (which already has
`wfp_row_can_be_selected_and_unconfirmed_from_a_real_guard_value`, a gate-level test constructing a
synthetic-but-real `NetworkEnforcementGuard::WfpServiceManaged` value with `installed_filter_count:
0` and driving the real registry + `apply_startup_attestation_gate`), `FirewallRulesEgress` has no
equivalent test — it is currently `MANUALLY_VERIFIED` on the grounds that "no force-unavailable
seam was shipped for this row." That reasoning conflates "no seam" with "no test" — the exact same
gate-level pattern the WFP test already uses works here too, using the pre-existing
`firewall_rules_guard_with_rule_count()` fixture and `firewall_rules_report()` (both already in the
tree), with NO new production seam and NO live `netsh` call required.

Purpose: the banner text must be truthful (CINT-02's own "never presents a confinement guarantee it
did not confirm" extends to the OPERATOR-FACING explanation of a downgrade, not just the decision
itself), and every automatable registry row should have a real test per the operator's locked
"automate what is automatable" decision.
Output: an unconditional `tracing::warn!` in the `ProceedDowngraded` arm; a new gate-level test for
`FirewallRulesEgress` that Plan 117-18 will register as automated in the meta-test's discovery.
</objective>

                tracing::warn!("... downgraded_layers={dedup_key}");             // only on the Err arm
