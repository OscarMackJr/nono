pub fn hash_chain(previous: Option<&ContentHash>, leaf_hash: &ContentHash) -> ContentHash {
    let mut hasher = Sha256::new();

}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Core type definition → all three binary producers | The struct shape is the ONLY thing constraining what a producer can put in a receipt; a permissive shape here is a permanent leak surface downstream. |
| Receipt chain construction → offline verifier | The chain must be verifiable without any secret the emitting process held (D-25) — a design mistake here (e.g. reintroducing a key) breaks RCPT-02's actual use case for every downstream plan. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-118-01 | Information Disclosure | `EnforcementReceipt` struct shape | mitigate | Type-allowlist scan (Task 3) with a named single exception (`session_id: String`); no other `String`/`PathBuf`/raw-bytes field permitted — enforced at test time, per D-14/D-05. |
| T-118-02 | Tampering | `receipt_chain.rs`'s hash construction | mitigate | Keyless SHA-256 domain-separated chain (D-25) mirroring the already-reviewed core audit construction (`audit.rs::hash_chain`) rather than inventing a new one; distinct domain constant from both existing chains (D-11) so cross-chain confusion cannot occur. |
| T-118-03 | Spoofing | `EnforcementReceipt.entry_path`/`.token_arm` fields | accept (documented) | These are `&'static str` produced by the CALLER (the supervisor binary), never by the confined process (D-19) — the type system cannot enforce this by itself in this plan; later wiring plans (118-07/08/06) must never source these strings from process-controlled input, which this plan's module doc states as an explicit invariant for those plans to honor. |
| T-118-04 | Repudiation | `SessionOutcome` collapsing `Refused{layer}` detail | accept (documented) | `SessionOutcome` is a 2-variant enum (D-02) with no embedded layer detail by design — the failing layer is recoverable from the per-row census (`layers: Vec<LayerReceiptRow>`), avoiding a duplicated, potentially-inconsistent second source of truth. |
</threat_model>
