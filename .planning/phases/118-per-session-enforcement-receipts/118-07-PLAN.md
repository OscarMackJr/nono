}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `CREATE_SUSPENDED` window → `ResumeThread` | The receipt write must complete strictly before the child executes a single instruction (D-03) — this is the same trust boundary D-21's attestation gate already protects, extended to cover the record, not just the decision. |
| Emitter failure → session continuation decision | A sink-write failure must never silently become either "session aborted for no visible reason" or "session ran with no failure evidence" — D-04's explicit two-branch posture. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-118-21 | Repudiation | Receipt write happening AFTER `ResumeThread` (ordering bug) | mitigate | Task 1 places the write inside the match arms, all of which resolve BEFORE the function returns to its caller, which itself only calls `resume_contained_process` AFTER `apply_startup_attestation_gate` returns `Ok` (existing, unmodified call-site ordering at `launch.rs:2565-2586`) — the ordering invariant is structural, not merely tested. |
| T-118-22 | Denial of Service | `require_receipts=true` combined with a systemically broken sink (e.g. permanently unwritable directory) refusing EVERY launch | accept (documented) | This is the intended fail-closed behavior an operator explicitly opted into (D-04) — Plan 118-10's manual checkpoint verifies the sink guard functions correctly on this host before this becomes a real fleet concern. |
| T-118-23 | Repudiation | Spoofing the receipt's identity fields via a claim from the confined process | mitigate | `session_id`/`pid`/`entry_path`/`token_arm` are all sourced from the SUPERVISOR's own already-known launch parameters (`session_id` string, `process` handle via `GetProcessId`, the `EntryPath`/`WindowsTokenArm` the supervisor itself selected) — never from anything read out of the child process's memory, argv, or environment (D-19, carried and enforced by construction in this wiring). |
</threat_model>
