<objective>
Restructure `nono-agentd`'s `daemon_attest_and_decide` from a 5-of-13-layer early-return chain
into a collect-all-then-decide pass (D-26) — a fail-direction change to shipped security code that
must ship with its own equivalence proof, not merely a new-rows-present test. Give the daemon a
genuine 13-row census by pairing the restructured 5 modelled rows with a daemon-local, drift-guarded
8-row `NotApplicable` expectancy table for the layers `nono-agentd` structurally cannot reach
(Finding 1b/1c, Open Question 2's recommended resolution). Prove the daemon's own receipt-assembly
path is content-free with its own sentinel round-trip test — the type-allowlist scan (Plan 118-01)
covers all three producers structurally by TYPE, but the daemon is an independent producer with its
own data flow and its own chance to source a field from something not actually opaque, which only a
per-producer behavioral test can catch (class coverage, not just placement).

Purpose: without this, a daemon-session receipt would either be a 5-row partial census or would
silently invent `Unconfirmed`/`NotApplicable` values for the other 8 rows with no drift protection
— exactly the honesty gap this milestone exists to close.
Output: restructured `daemon_attest_and_decide`, daemon-local expectancy table, daemon receipt
assembly helper, equivalence-proof test, cross-check drift guard, daemon sentinel round-trip test.
</objective>
