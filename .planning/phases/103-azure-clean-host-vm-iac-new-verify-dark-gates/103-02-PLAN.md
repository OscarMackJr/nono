`Assert-TrustedSignature -Path <string> -Mode 'Strict'|'Informational'` — the sole public entry
point. In `-Mode Strict`, it throws on any non-Valid GAS status or non-zero `signtool verify /pa
/v` exit (byte-for-byte preserved `if ($gas.Status -ne 'Valid')` gate, never weakened). Returns a
