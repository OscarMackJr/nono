argument so a new call site that omits it fails to compile rather than silently defaulting to
uncategorised; categorise the three previously-uncategorised sites (`connect.rs`'s HTTPS

DRAIN-02 round-trip test (Plan 115-05) does not need its own hand-written variant list.

receipts build on — it must be clean before it is built on.

migrated, `InterceptHandshakeFailed` removed, and a self-enumerating `ALL` const + guard on
`NetworkAuditDenialCategory`.
